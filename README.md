# FateBound — Deck Builder

Application web de création de decks pour **FateBound**, un jeu de cartes à trois races (Mort-Vivant, Humain, Démon). Le projet est composé d'un backend Node.js/Express/MySQL et d'un frontend React/Vite.

---

## Structure du projet

```
wyrdane/
├── backend/     → API REST (Node.js, Express, MySQL)
└── frontend/    → Interface (React, Vite, React Router)
```

---

## Prérequis

- Node.js ≥ 18
- npm
- MySQL ≥ 8

---

## Stack technique

**Backend** : Express, mysql2, bcrypt, jsonwebtoken, dotenv, cors, nodemon

**Frontend** : React, Vite, react-router-dom
